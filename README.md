# 30-day-AI-Cohort
A hands-on 30-day AI engineering project focused on building practical AI applications and understanding the systems behind them.

## About

This repository contains my work, experiments, notebooks, and projects completed throughout the 30-Day AI Cohort.

The project progressively builds an AI-powered healthcare coverage assistant, starting with local LLM interaction and a FastAPI backend, then moving into structured data ingestion, SQL querying, and eventually connecting these components into a chatbot.
